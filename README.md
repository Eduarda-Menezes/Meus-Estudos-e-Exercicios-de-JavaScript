## 🧪 Exercícios Realizados

### 🟡 1. Primeiros Passos

* **Ex1 - Olá Mundo:** Primeiro contato com exibição de mensagens (`console.log`).
* **Ex2 - Apresentação:** Manipulação e exibição de variáveis simples.
* **Ex3 - Calculadora Simples:** Operações matemáticas básicas (+, -, *, /).

### 🟠 2. Entrada de Dados

* **Ex1 - Calculando Idade:** Leitura de dados do usuário via prompt/formulário para cálculo simples.
* **Ex2 - Calculando Média:** Processamento de múltiplos valores e exibição do resultado.
* **Ex3 - Celsius para Fahrenheit:** Conversão de unidades e manipulação numérica.

### 🔴 3. Condicionais

* **Ex1 - Verificar Idade:** Validação de maioridade usando `if/else`.
* **Ex2 - Verificar Positivo / Negativo:** Validação de sinais numéricos.
* **Ex3 - Verificar Aprovado / Reprovado:** Aplicação de médias com tomada de decisão.
* **Ex4 - Verificar Maior / Menor:** Comparação direta entre valores.
